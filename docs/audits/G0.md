## Найдено и исправлено при аудите

1. Линтер шёл до сборки и на чистом клоне падал (21 ошибка): type-aware правила читают типы пакетов из `dist`. Порядок в CI и `pnpm run ci`: сборка, затем линтер.
2. Bind-mount скрипта инициализации Postgres зависел от прав каталогов на хосте. Заменён на `configs` Compose.

## Что не проверено

- Первые прогоны GitHub Actions — после пуша.

## Открытые решения, переходящие в следующие гейты

1. Провайдер БД — ADR-0001, закрыть к G1.
2. Хостинг — ADR-0004, закрыть до этапа C; зависит от наблюдений этапа A о входе с адреса дата-центра.
3. Масштаб USDT — задаётся адаптером по данным Walt (02 §10). До этого `ASSET_SCALE_USDT` в `.env.example` пустой, и `MoneyFactory` без него не создаётся.
4. Репозиторий публичный — сделать приватным до кода, связанного с реальными экранами (план, раздел «Публичность»).
5. EX-040 в ТЗ: заменить «Postgres/Neon» на ссылку на ADR-0001.

## Решение

G0 пройден. `docs/current-gate` = `G0`. Треки 1–7 можно запускать параллельно по правилам владения из плана.
