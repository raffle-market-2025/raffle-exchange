# Возможности провайдеров и вопросы подключения

Версия 1.3 • 28 октября 2026.

Проверено по открытым официальным источникам 28 октября 2026. API-ключи, банковские сессии и реальные сделки при подготовке ТЗ не использовались. Визуальный статус мерчанта на скриншоте — контекст аккаунта, не проверка серверных полномочий.

## 1 Walt

[Официальная справка P2P API](https://help.ru.walt.io/article/933-p2p-api-ru): API предназначен для цен и объявлений; торговля через него не поддерживается. [Техническая документация](https://docs.walt.io/p2p): метод online items, X-API-Key и параметры пагинации. [Правила P2P](https://walt.io/docs/p2p-market-terms): реклама сторонних услуг в объявлениях/чате запрещена; официальные способы интеграции должны соблюдаться.

Выбранный заказчиком путь — торговые действия через авторизованный веб-интерфейс Walt. Отдельный trading API больше не является условием реализации. Рыночный API сохраняется для чтения цен и объявлений.

Обследовать в текущей сессии: доступность USDT/UAH и методов Ощад; очередь и ID своих сделок; создание/принятие/отмена; изменение объявлений; escrow и конечные статусы; доступ к скрину оплаты; подтверждение release; требуемые 2FA; историю после перезахода; комиссии и ограничения конкурентности. Результат описан в [ТЗ веб-исполнителя](07-walt-web-spec.md).

Проверка интерфейса не означает подтверждённую допустимость автоматизации со стороны Walt. Действующие правила ограничивают сторонние инструменты; выбранный веб-путь может повлечь ограничение сессии/аккаунта. Этот риск сохраняется явно. Обход защит и продолжение торговли после блокировки не проектируются. Реклама в Walt остаётся исключённой независимо от выбранного способа исполнения.

## 2 Ощад

Факт от заказчика: UAH обслуживается через Ощад, сейчас только веб-форма; есть push и возможность проверять баланс карты. Достаточность реквизитов push и истории для идентификации движения ещё не установлена. Не предполагать наличие API, open banking доступа или конкретного типа счёта.

[Официальное руководство CorpLight](https://cl.oschadbank.ua/assets/doc/User_Manual.htm) используется как пример раздельных стадий создания/подписи/отправки. Оно не определяет доступный заказчику продукт.

Подтвердить:

1. Как называется фактический кабинет и каков его официальный URL?
2. Разрешён ли выбранный тип торговых поступлений и выплат на данном счёте?
3. Допускается ли программная подготовка/обработка веб-форм; какие ограничения установлены банком?
4. Какой шаг требует OTP, приложения, КЭП или иного личного подтверждения?
5. Можно ли получить официальную историю/выписку с устойчивыми идентификаторами, статусами и доступными данными плательщика?
6. Как проверяются неизвестный итог отправки, банковский отказ, возврат и повторный документ?
7. Какие комиссии и лимиты действуют по конкретному методу, счёту и получателю?
8. Может ли клиентская сумма прийти без уникального назначения и как в таком случае обеспечить однозначное сопоставление?

Результат обследования — конкретная карта формы и доступных операций в `06-oschad-web-spec.md`, а не общая надпись «банк подключён».

## 3 Канал сообщений

[Telegram Bot API](https://core.telegram.org/bots/api) — контракт собственного бота, отдельно от Walt. Для реальной доставки нужно проверить существующего бота, разрешённую связь chatId с нашим пользователем и согласие на промо. Публичный идентификатор автора объявления не заменяет эти условия.

## 4 Решения при ограничениях

Отсутствие у Walt торгового API не останавливает выбранный веб-путь. Если конкретное необходимое действие недоступно в текущей сессии, только это действие/направление переводится в assisted или paused с сохранением обязательств.

Если Ощад требует человека на каждом платеже, доступен assisted-контур с задачей на подтверждение. Он не выдаётся за unattended-режим.

Если нет собственного разрешённого рекламного канала, приглашение может быть показано в нашем интерфейсе, но отправка в Walt не выполняется. Причина недоставки учитывается в воронке.

Другой исполнитель/банк может быть подключён позже отдельным решением заказчика; в этом ТЗ Walt и Ощад не заменены молча сторонними сервисами.
