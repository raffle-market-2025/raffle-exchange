# walt-browser-worker

**Этап C.** Пустой до завершения этапа A (обследование авторизованного веб-интерфейса Walt).

Будет реализовывать контракт из `@raffle-exchange/walt-adapter` (07 §3) в постоянном процессе на отдельном хосте с устойчивым профилем ([ADR-0004](../../docs/adr/0004-hosting.md)).

Что запрещено ТЗ и никогда здесь не появится:

- обход CAPTCHA и 2FA, перехват чужой сессии, недокументированные приватные HTTP-методы (EX-008);
- координатный клик «примерно по кнопке» и поиск похожей кнопки при изменённой раскладке (07 §2);
- второй активный исполнитель на профиль (EC-014);
- реклама Raffle в чате или объявлениях Walt (PR-003).

Профиль браузера, cookies, storage state и трейсы обследования в git не попадают — это проверяет `scripts/check-forbidden-files.mjs`.
