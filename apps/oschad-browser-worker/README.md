# oschad-browser-worker

**Этап C.** Пустой до завершения этапа A (обследование фактического кабинета Ощад: тип, домен, шаги подтверждения, выписка).

Будет реализовывать контракт из `@raffle-exchange/fiat-adapter` (06) в изолированном процессе с собственной сессией. Параллельность на сессию — 1 (06 §3).

Что запрещено ТЗ:

- перехват или автоматический ввод OTP, подтверждений в приложении, КЭП (06 §2, W-04);
- выбор CorpLight или перевода по IBAN по одному названию банка (06 §1, W-01);
- недокументированные внутренние HTTP-методы банка (06 §3);
- передача банковской сессии во frontend, аналитику или AI.

Если каждый платёж требует личного подтверждения, режим — `WEB_ASSISTED` с задачей оператору, а не «полный автомат» (06 §2).
