# exchange-worker

Трек 3 этапа B: исполнение и восстановление. Задачи T3.1–T3.9 в [плане](../../docs/stage-b-plan.md).

Очередь — transactional outbox в той же БД, что и состояние сделки ([ADR-0002](../../docs/adr/0002-queue-transactional-outbox.md)).

Ключевые запреты из [08 §4](../../docs/spec/08-execution-contract.md):

- истёкший lease не доказывает, что прежний исполнитель не кликнул; второй executor на профиль не стартует без доказанной остановки первого (EC-014);
- `ATTEMPT_STARTED` фиксируется устойчиво до клика; после него отсутствие ответа — `UNKNOWN_RESULT`, а не повод повторить (EC-017);
- новая `sequence` не создаёт права на второй `RELEASE_USDT` или `PAY_UAH` по той же обязанности (EC-016);
- после восстановления из бэкапа сначала сверка внешних операций, немедленный replay старого outbox запрещён (02 §12).
