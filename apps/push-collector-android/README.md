# push-collector-android

Сборщик банковских push на выделенном Android-устройстве. Каркас — задача T5.6 трека 5; разбор текста уведомлений — только после этапа A.

Почему Android: на iOS приложение не может читать уведомления других приложений, а банковского webhook нет (06 §8.1).

Требования из [06 §8](../../docs/spec/06-oschad-web-spec.md) и [08](../../docs/spec/08-execution-contract.md) EC-026, EC-037:

- `NotificationListenerService` с фильтром по пакету приложения Ощада и по выделенной карте; уведомления других приложений не читаются и не пересылаются;
- аутентификация устройства ключом, `deviceId + epoch + seq`, защита от replay, ограниченный возраст события, heartbeat;
- новая `epoch` при переустановке, чтобы сброс `seq` не терял и не повторял события;
- OTP, коды подтверждения и пароли в конвейер не попадают;
- push — сигнал `FIAT_SIGNAL_RECEIVED`, а не подтверждение оплаты.

Сборка Kotlin/Gradle не входит в CI монорепо на этапе B до появления каркаса.
