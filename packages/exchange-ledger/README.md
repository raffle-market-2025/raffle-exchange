# exchange-ledger

Трек 2 этапа B: учёт и ликвидность.

Задачи T2.1–T2.6 из [плана этапа B](../../docs/stage-b-plan.md): двойная запись отдельно по UAH и USDT, дедупликация внешних движений, резервы, внешние блокировки и доступность с watermark, общий пул объявлений, возвраты и нераспределённые поступления.

Нормативная база: [02 §9](../../docs/spec/02-technical-spec.md), [08](../../docs/spec/08-execution-contract.md) EC-010…013, 020, 031, 038, 040; [01 §8](../../docs/spec/01-product-spec.md).

Правила пакета:

- проводка одного журнала сходится по каждому активу отдельно; проверка дублируется ограничением в БД (отложенный триггер, ADR-0003);
- резерв — модель доступности, а не дополнительный актив; escrow не вычитается дважды;
- неизвестная комиссия — расхождение, а не ноль;
- изменение статуса администратором не закрывает расхождение без ссылки на операцию или подписанного решения с корректирующими проводками.
