# fiat-adapter

Контракт гривневой стороны (трек 4, T4.1) и модель банковских доказательств (трек 5, T5.2–T5.5).

Нормативная база: [06](../../docs/spec/06-oschad-web-spec.md), [08 §6](../../docs/spec/08-execution-contract.md) EC-024…026, 035…037.

Правила пакета:

- push — сигнал, а не подтверждение оплаты; баланс — агрегат, а не конкретное движение;
- `verificationLevel` не повышается без ссылки на банковскую запись и актёра (EC-036);
- банковского API не предполагается; режим без человека не объявляется, пока каждый шаг не проверен на этапе C;
- OTP, пароли и подтверждения в приложении не перехватываются и не обходятся.
