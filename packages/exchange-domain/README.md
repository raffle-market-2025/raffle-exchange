# exchange-domain

Трек 1 этапа B. Владелец схемы БД до гейта G1.

Задачи T1.1–T1.7 из [плана этапа B](../../docs/stage-b-plan.md): машина состояний с фазами по направлениям, native-импорт, снимки условий `PRE_ACCEPT` / `PAYMENT_DETAILS_LOCKED`, денежная разбивка по ролям, модель дедлайна, таблица внешних статусов, событие завершения и решение по промо.

Нормативная база: [08](../../docs/spec/08-execution-contract.md) EC-001…004, 008, 009, 027…030, 034, 039, 041, 044; [02 §4–§6](../../docs/spec/02-technical-spec.md).

Правила пакета:

- никакого ввода-вывода; время только через `Clock` из `@raffle-exchange/core`;
- суммы только `Money`; `number` в денежной логике запрещён линтером;
- неизвестный внешний статус → `REVIEW_REQUIRED`, а не ближайший похожий;
- тесты помечаются ID сценария в имени: `it('[X-08] …')`, см. [матрицу](../../docs/traceability.md).
