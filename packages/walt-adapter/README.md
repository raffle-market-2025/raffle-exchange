# walt-adapter

Трек 4 этапа B: контракт, реестр возможностей и рыночные данные.

Задачи T4.1, T4.2, T4.4, T4.5 из [плана этапа B](../../docs/stage-b-plan.md).

Нормативная база: [07 §3](../../docs/spec/07-walt-web-spec.md), [02 §2–§3](../../docs/spec/02-technical-spec.md), [08](../../docs/spec/08-execution-contract.md) EC-019…023.

Правила пакета:

- интерфейс описывает наши функции (`observeOwnOrders`, `prepareAction`, `performPreparedAction`, …), а не методы Walt;
- непроверенная возможность трактуется как недоступная; `evidenceRef` обязателен для `supported: true`;
- рыночный клиент ходит только на один подтверждённый хост из конфигурации, без следования редиректу с ключом;
- публичный API — только чтение рынка; никаких торговых вызовов и скрытых приватных HTTP-методов.
